# Decisions

Each entry records a decision, the reason for it, and any later reversal. Reversals are added as new entries, not edits.

## 2026-10-26: Fixed-point prices

Prices are `int64_t` ticks (0.01 USD) everywhere inside the engine and on the wire. Floating-point prices accumulate rounding error and make equality checks unsafe.

## 2026-10-26: Synthetic order flow in LOBSTER format

LOBSTER sample files are distributed by request rather than as a public download, so the default dataset is generated by `microprice.synth` in the LOBSTER message and order book format. Licensed LOBSTER files placed in `data/lobster/` load through the same reader.

## 2026-10-26: kdb+ with a Python fallback

The tick store is written in q. kdb+ needs a license file that cannot be provisioned in CI, so every q analytic has a pandas reference implementation with the same name and output schema. Tests run the pandas path everywhere and compare against q when a q binary is on the PATH.
